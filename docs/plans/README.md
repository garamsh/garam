# Plans

Active work and its current state.

- [roadmap.md](./roadmap.md) — sequence of work and milestones.
- [current-state.md](./current-state.md) — what is done, what is open.
- `archive/` — completed or dropped plans, kept for reference.

A new plan starts as `YYYY-MM-DD-<topic>.md` and follows
[`../convention/planning.md`](../convention/planning.md).
Move to `archive/` once the work ships or is dropped.
